# Contributing

Open an issue or pull request describing the concrete request, observed behavior, and expected outcome. Remove secrets and personal data from examples.

Keep each skill focused and its description precise enough for discovery. Do not invent APIs, promise unmeasured savings, impose a framework on unrelated projects, or expand user authorization. Detailed resources should be linked and loaded only when relevant.

Run `python scripts/validate_skills.py` before submitting. For changes to agent behavior, include a realistic evaluation scenario and disclose whether it has actually been tested. Structure validation alone is not behavioral verification.

Use Conventional Commits such as `fix: preserve authorization in memory retrieval`. Contributions are submitted under this repository's Apache-2.0 license.

## Evidence before expansion

This is an experimental reference collection. Propose changes against a demonstrated recurring problem and report what the existing host or project instructions already provide. Prefer project-specific examples and repeatable comparisons to adding generic rules or new modules. A report that a module adds no benefit is useful feedback too. Do not claim infrastructure behavior from instruction-file tests.
