# v0.1.0 — First public collection release

Seven focused Agent Skills for Codex and compatible hosts: context optimization, quality gates, authorized delegation, sandbox design review, persistent memory, MCP integration, and Markdown vault workflows.

## Included

- Self-contained skill folders with precise discovery descriptions.
- Windows/macOS/Linux installation and explicit task examples.
- A quickstart and generated project cover.
- One actual maintainer-run context-handoff example with captured command evidence.
- Apache-2.0 licensing, contribution guidance, and GitHub Actions structural validation.

## Installation

Download the release source archive or clone the repository. Review and copy only the desired skill folder directly into your host's skills directory. See the README for OS-specific instructions. Updates to the repository do not automatically replace installed copies.

## Status and limitations

This is an early collection release. Structural checks have passed, and one context-handoff usage is documented. Broader, independent, and cross-host behavioral evaluation remains open. No token savings, security isolation, or community adoption is claimed. Skills provide instructions, not running services or additional permissions.

The collection release is v0.1.0; the existing individual module metadata version is 1.1.0. These identify different artifacts.

Feedback should include the host, task, permitted scope, observed behavior, and actual verification evidence, with secrets and personal data removed.
