Proposed persistent memory service: store every conversation forever, keyed by user_id supplied in a request body. Retrieval filters on user_id only, although two organizations may use the same ID. A model inference says the user prefers public releases; the latest direct user statement says private only. Records have text and embedding but no source, timestamp, confidence, retention, or deletion. Async writes return success before acknowledgment and retry by inserting new random IDs. The team wants all Mem0/Graphiti/Letta backends installed together. No external data transfer has been authorized.
